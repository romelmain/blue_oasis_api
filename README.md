# blue_oasis_api

blue_oasis_api: Api developed in Spring Boot in order to create reservations, check in, check out for the Blue Oasis Hotel

### Consola:

### Normal sin perfiles

- mvn clean
- mvn install

### Normal con perfiles

- mvn clean

### Para desarrollo

- mvn install -Pdev

### Para QA

- mvn install -Pstg

### Para Produccion

- mvn install -Pprod

### Para Ejecutar

- java -jar target\blue_oasis-0.0.1-SNAPSHOT.jar
